# KaagazCheck: कागज़ चेक

The government checks your papers after you apply and rejects you months later. KaagazCheck checks them **before** you apply, in Hindi, and tells you exactly what to fix.

> Work in progress (Cline AI Builder Hackathon). The full README (problem, architecture, how Cline was used) comes in the final task.

## Setup
Requires Node 22+.

```powershell
npm install
copy .env.example .env.local   # then fill in CLINE_API_KEY and CLINE_MODEL
npm run dev
```

`npm test` · `npm run typecheck` · `npm run lint` · `npm run build`
